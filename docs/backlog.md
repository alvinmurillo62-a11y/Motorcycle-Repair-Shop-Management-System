# Motorcycle Repair Shop Management System

## Customer

### Create
As a staff, I want to add a customer so that customer information can be saved.

### Read (List)
As a staff, I want to view all customers so that I can find customer records.

### Read (Details)
As a staff, I want to view customer details so that I can see complete information.

### Update
As a staff, I want to edit customer information so that records remain accurate.

### Delete
As a staff, I want to delete customer records after confirmation.
